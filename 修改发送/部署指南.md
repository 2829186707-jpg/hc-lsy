# 情侣空间部署指南

## 一、你收到的文件

`couple-space-template/` 文件夹是一个完整的情侣空间网站模板，纯静态页面，不需要服务器，部署到 GitHub Pages 即可免费使用。

## 二、部署步骤（约 10 分钟）

### 第 1 步：注册/登录 GitHub
- 访问 https://github.com
- 注册账号（如果没有），邮箱验证

### 第 2 步：创建私有仓库
1. 点击右上角 `+` → `New repository`
2. Repository name 随便填（比如 `our-space`）
3. 选择 **Private**（私有，只有你们能看）
4. 勾选 `Add a README file`（可选）
5. 点击 `Create repository`

### 第 3 步：上传文件
1. 在仓库页面点击 `uploading an existing file`
2. 把 `couple-space-template` 文件夹里的**所有文件和文件夹**拖进去
   - index.html
   - css/ 文件夹
   - js/ 文件夹
   - manifest.json
   - service-worker.js
   - icon.svg
   - .gitignore
   - README.md
3. 底部点击 `Commit changes`

### 第 4 步：开启 GitHub Pages
1. 仓库页面 → `Settings`（设置）
2. 左侧菜单找到 `Pages`
3. `Source` 选择 `Deploy from a branch`
4. `Branch` 选择 `main`，文件夹选 `/ (root)`
5. 点击 `Save`
6. 等 1-2 分钟，页面上方会出现网址：`https://你的用户名.github.io/仓库名/`

### 第 5 步：打开网站并配置
1. 访问上面的网址
2. 默认密码 `123456`，选择任意一个身份登录
3. 进入后点击右上角 ⚙️ 设置：
   - **在一起的日期**：设置你们在一起的日子
   - **纪念日管理**：添加生日、纪念日等倒计时
   - **异地天气**：填写两人所在城市
   - **修改密码**：两人都改成自己的密码
4. 开始上传照片、写日记、添加心愿吧 ♥

### 第 6 步（推荐）：配置数据同步
不配置的话，数据只存在当前浏览器，换设备/清缓存会丢失。配置后多设备同步：

1. GitHub → 右上角头像 → `Settings`
2. 左侧最底部 `Developer settings`
3. `Personal access tokens` → `Fine-grained tokens`
4. `Generate new token`
5. Token name 随便填（比如 `couple-space`）
6. Expiration 选 `No expiration`（或自定义）
7. `Repository access` → `Only select repositories` → 选你们的仓库
8. `Permissions` → `Repository permissions` → `Contents` → 选 `Read and write`
9. 底部 `Generate token`
10. **复制生成的 token**（只显示一次！）
11. 回到情侣空间网站 → 设置 → GitHub 数据同步
    - 仓库所有者：你的 GitHub 用户名
    - 仓库名称：仓库名
    - Token：粘贴刚才复制的
12. 保存配置，数据会自动同步

## 三、手机上使用（PWA）

### iPhone (Safari)
1. Safari 打开网站
2. 底部分享按钮 → `添加到主屏幕`
3. 桌面出现图标，点击即可以 App 方式打开

### Android (Chrome)
1. Chrome 打开网站
2. 右上角菜单 → `添加到主屏幕` / `安装应用`
3. 桌面出现图标

## 四、注意事项

1. **隐私**：仓库设为 Private，数据存在你们自己的 GitHub 仓库里
2. **密码**：登录后立即修改默认密码，两人各自改自己的
3. **数据备份**：定期在设置 → 数据管理 → 导出数据，下载 JSON 备份
4. **图片数量**：GitHub 仓库有容量限制（建议照片总数不超过 500 张），图片会自动压缩
5. **两人同时编辑**：支持两人同时使用，数据每 60 秒自动同步

## 五、常见问题

**Q: 网站打不开？**
A: GitHub Pages 部署需要 1-2 分钟，耐心等待。确认 Settings → Pages 里的网址是绿色的。

**Q: 换手机后数据没了？**
A: 需要配置 GitHub 数据同步（第 6 步）。配置后登录会自动拉取云端数据。

**Q: 照片上传失败？**
A: 检查 GitHub Token 是否有 Contents 读写权限，仓库是否还有空间。单张照片会自动压缩到 1280px 宽度。

**Q: 想改两人的显示名字？**
A: 当前版本名字在代码里，需要修改 index.html 和 js/app.js 中的对应文字。后续版本会支持设置页自定义名字。
